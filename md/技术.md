# 🚄购买火车票座位项目（前后端分离｜SSM 技术栈整体方案优化整理）

## 📋项目概述

**项目名称：火车票座位购票系统（前后端分离）**

> 分为两大模块：**Vue 前端模块、后端 SSM 后端模块**；实现火车票查询、余票、选座、购票业务。

## 🛠完整技术栈

### ✨后端（SSM 原生 Spring，非 SpringBoot）

- 核心框架：**Spring + SpringMVC + MyBatis**
- 权限安全：**SpringSecurity**（认证、授权、Web 安全防护）
- 数据库连接池：**Druid**
- 缓存架构：**三层缓存 L1 本地缓存 (Caffeine) + L2‑Redis 分布式缓存 + L3‑MySQL 数据库**
- 对象分层：
  - **DTO：Controller 入参，接收前端提交表单；使用 JSR‑303 做参数校验**
  - **BO：Service 层业务对象，Service 之间的数据传递、多表业务组装**
  - **DO：数据库实体，与 MySQL 数据表一一对应**
  - **VO：Controller 返回前端视图出参对象，屏蔽数据库敏感字段**
- 工具与日志：
  - **Lombok**：简化实体类 get/set、构造方法
  - **Logback**：日志输出配置（`logback‑spring.xml`）
  - **Knife4j**：RESTful 风格接口在线文档调试
- 公共包分层：
  - `common`：统一返回结果 Resp、自定义业务异常、全局异常处理器、常量、枚举（车票状态、订单状态）
  - `config`：SpringSecurity 配置、Druid 连接池配置、Redis 配置、Caffeine 本地缓存配置
  - `util`：通用工具类（日期工具、座位算法工具等）
  - `aop`：可选，日志记录切面
- API 规范：**RESTful 风格接口开发**

> ⚠️原生 SSM 需要外部 Tomcat 部署运行；所有配置采用 XML + 少量注解开发。

### ✨前端

- **Vue2 / Vue3**；浏览器本地前端缓存 (localStorage/sessionStorage)；

> 📌完整缓存体系说明：**前端浏览器缓存 + 后端三层缓存 (L1 本地 Caffeine、L2 Redis、L3 MySQL)**

## 🧩缓存层级完整说明（三级缓存）

1. **前端缓存（浏览器端）**：localStorage/sessionStorage，缓存基础字典（站点列表），减少 http 请求；
2. **后端‑L1：JVM 本地缓存 (Caffeine)，进程内高速缓存；优先查询 L1**
3. **后端‑L2：Redis 分布式缓存；L1 未命中再访问 Redis；适合车票余票缓存**
4. **后端‑L3：MySQL 数据库；缓存都未命中查询数据库；写操作后主动失效 L1+L2 缓存，保证缓存一致性**
